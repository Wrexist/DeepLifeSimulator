# 3D Avatar Style Options — pick one

Three candidate 3D art directions to replace the current warm-amber Pixar
faces. Each folder holds a `STYLE.md` with the full style DNA, negative
prompt, and worked sample prompts.

**How choosing works:** the per-face identity lines (who each face is — "young
adult woman, fair skin, long auburn hair…") already exist for the whole
~75-face library in `docs/avatar-portraits-prompts.md`. To regenerate the
library in a chosen style, combine that doc's identity lines with the chosen
option's STYLE DNA instead of the old amber one. Filenames and the seeded
picker stay exactly the same — drop the new PNGs into
`assets/images/Face/pool/` and everything just works.

| Option | Look | One-liner |
| --- | --- | --- |
| 1 · Modern Pixar | Same friendly 3D, **dark-studio glow-up** | Keeps the approachable Pixar feel but on the app's deep-navy palette with cinematic rim light — no more orange glow, sparkles, or hearts. |
| 2 · Cinematic Semi-Realistic | Premium game-character render | More grown-up, moody character portraits (think modern AAA menu screens). Highest "wow", least cartoony. |
| 3 · Stylized Clay Toy | Matte clay / vinyl-figure look | Collectible-figure charm, chunky shapes, soft studio light. Distinctive and very consistent across a big set. |

All three keep: square 1024×1024, head-and-shoulders, centered, front-facing,
one character, no text — so they slot into the existing pool without layout
changes.
