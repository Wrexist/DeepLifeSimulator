# Option 3 · Stylized Clay Toy — matte vinyl-figure look

Characters as premium collectible figures: chunky simplified shapes, matte
clay materials, soft studio light. Extremely consistent across a large set
and instantly recognizable as "this game's look".

## Style DNA (prepend to every identity line)

> Stylized 3D clay-render character head, matte plasticine/vinyl-toy
> material, chunky simplified shapes, soft rounded features, tiny glossy
> bead eyes, sculpted chunky hair with visible smooth clay finish. Soft even
> studio lighting with one gentle top-left key light, subtle ambient
> occlusion in the creases. Deep navy-black background (#0B1220) with a
> faint circular blue floor-glow behind the bust. Head and shoulders,
> centered, facing forward, pleasant calm micro-smile. Square, 1024x1024. No text.

## Negative prompt

```
text, watermark, photorealistic skin, realistic pores, uncanny, glossy plastic
shine, harsh shadows, flat 2D vector, line-art, full body, hands, multiple
people, busy background, bright warm background, low resolution
```
