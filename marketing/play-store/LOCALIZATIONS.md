# Play store listings - languages worth adding

The app UI is **English**. Play lets you localise the *listing* independently, so
a localised listing ranks for local keywords even with an English UI. That is a
real download lever, but it is a trade: a player who installs from a Japanese
listing and finds an English game may rate lower. So this list is ordered by
**value vs. risk**, and the recommendation is to ship the first group now and
hold the CJK/Cyrillic group until the UI itself is translated.

**How to add them:** Play Console -> *Öka antalet användare* -> *Butiksnärvaro* ->
*Huvudbutikslistning* -> **Hantera översättningar** -> add the language -> paste
title / short / full description below. Never translate the long description
with a machine tool and ship it unseen - keyword-stuffed machine text is the
thing Play demotes.

## Group 2 - only after the app UI is translated (big markets, bad fit today)

`ja`, `ko`, `zh-Hans`, `zh-Hant`, `ru`, `ar-SA`, `hi`, `th`, `vi`. These are
large storefronts, but an English-only game converts poorly and ratings suffer
when the listing promises a local experience. Localise the **game UI** first,
then add these listings - the same copy structure above applies.

## Rules that keep you out of trouble

- **Never machine-translate unseen.** Play's policy and its ranking both punish
  keyword-stuffed, broken translation.
- **One listing language per real audience.** Don't add a language just to
  duplicate keywords; the main storefront's keywords come from the default
  listing anyway.
- **Keep the title under 30 and short under 80** in every language or Play
  truncates silently (same trap as Apple).
