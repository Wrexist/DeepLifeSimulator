## notes

```text
- Subtitle "Η προσομοίωση ζωής που μετράει" carries the top Greek genre term "προσομοίωση ζωής" (life simulation) with a double meaning of "μετράει" (matters / counts money) - native marketing, not a translation.
- English "life simulator" is already indexed via the app name, so the keyword field spends its 100 chars on native terms: λεφτά (colloquial "money", higher volume than χρήματα), καριέρα, επένδυση, επιχείρηση, χρεοκοπία, φυλακή.
- Kept English "tycoon" - Greek players search the genre in English; native "μαγνάτης" added for the same intent in Greek.
- Greek App Store users often type without accent marks; Apple normalizes diacritics, so accented forms are safe and correct.
- Description uses ενικός (informal singular) throughout - standard register for Greek mobile games; What's New addresses the community in plural, which is idiomatic for patch notes.
- A/B test suggestion: subtitle vs. "Χτίσε περιουσία από το μηδέν" (fortune angle, no genre term) once the genre keyword ranking is established.
```
