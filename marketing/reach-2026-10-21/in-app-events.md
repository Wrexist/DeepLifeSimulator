# App Store in-app events (and Play promotional content)
Copy for one in-app event per Live Ops event in `support-site/liveops.json`. Limits checked by script: name ≤30, short description ≤50, long description ≤120 characters.
Where: App Store Connect › your app › **In-App Events** › Create. Each event needs a 1920×1080 event card image and a 3840×2160 (or 1080×1920 portrait) event details image or video; use the Halloween/holiday art you already have in-game, or a screenshot with a seasonal frame. Events can be promoted up to 14 days before they start and last up to 31 days, so long Live Ops windows are split into two cards. Apple usually reviews them within a day.
Deep link: `deeplifesim://` is not set up, so leave the deep link empty; tapping the card opens the app.
Purpose: pick **Appropriate for all users** (shows to new and existing players), so the card also appears in search results for people who do not have the game yet.
