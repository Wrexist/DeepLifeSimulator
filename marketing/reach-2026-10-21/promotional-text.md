# App Store promotional text, rotating with Live Ops

Promotional text (170 characters) is the only App Store field you can change **without a review**. It shows above the description on the product page. Swap it when each Live Ops event starts, then back to the evergreen line in `marketing/aso/metadata.mjs` between events.

Where: App Store Connect › your app › the current version (or the live one) › Promotional Text › Save.
