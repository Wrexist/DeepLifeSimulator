# R03: Make release validation fail on incomplete checks

Priority: P1. Dependencies: R00.

## Master prompt

The existing browser release validator exits zero when checks are UNREACHED. Make a release pass require the expected checks, no duplicates, no failed or unreached gates. Preserve diagnostic warnings distinctly. Test empty, partial and malformed results as failures. Reuse the existing harness and scripts rather than adding another release framework.

## Acceptance criteria

- UNREACHED and empty/partial required coverage fail
- Fully reached passing required checks pass
- Malformed and duplicate results cannot claim success

Apply `tasks/release/CONTRACT.md`. Re-check current source before implementing.
