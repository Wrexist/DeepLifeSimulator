# R01: Prevent stale saves overwriting newer progress

Priority: P1. Dependencies: R00.

## Master prompt

Reproduce an older double-buffer save whose storage write stalls beyond the mutex watchdog while a second save completes. Fix serialization so timeout cannot create concurrent writers. Preserve bounded waiter failure, release ownership, caller error handling and recovery after the real holder releases. Do not change the persisted schema.

## Acceptance criteria

- Regression fails on baseline and passes after fix
- A stalled old writer cannot overwrite a completed newer save
- Save/integration/stress suites pass and timeout caller contracts reviewed

Apply `tasks/release/CONTRACT.md`. Re-check current source before implementing.
